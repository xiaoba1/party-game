# 如何获取聚会游戏集安装包

本地 Gradle 打包容易因网络卡住。**推荐用云打包**，10 分钟左右即可拿到 APK，无需再折腾 Android 环境。

---

## 方案一：GitHub 云打包（推荐）

GitHub 服务器在国外，能正常下载 Android 依赖，一次配置永久可用。

### 步骤

1. **注册 GitHub**（若还没有）：https://github.com/signup

2. **创建空仓库**
   - 打开 https://github.com/new
   - 仓库名例如 `party-game`
   - 选 Public，不要勾选 README
   - 点 Create repository

3. **上传本项目代码**（在项目目录 `e:\TraeCode\game` 打开 PowerShell）：

```powershell
cd e:\TraeCode\game
git init
git add .
git commit -m "feat: 聚会游戏集初版"
git branch -M main
git remote add origin https://github.com/你的用户名/party-game.git
git push -u origin main
```

4. **等待自动打包**
   - 打开仓库 → 顶部 **Actions** 标签
   - 看到 `Build Android APK` 在跑（约 5～15 分钟）
   - 绿色 ✓ 后点进去 → 底部 **Artifacts** → 下载 `party-game-apk`
   - 解压得到 `app-release.apk`

5. **装到手机**
   - 把 APK 发到微信/QQ/网盘
   - 安卓手机允许「安装未知来源应用」后点击安装

> 以后改代码只需 `git push`，Actions 会自动重新打包。

---

## 方案二：手机 USB 直连调试（有安卓线时）

不用打 APK，直接装到手机，适合你自己先试用。

1. 手机开启 **开发者选项** → **USB 调试**
2. 数据线连电脑，手机上点「允许调试」
3. 运行：

```powershell
cd e:\TraeCode\game
.\scripts\run.ps1
```

脚本会自动检测手机并安装。**首次仍可能下载 Gradle 依赖**，网络不好时仍可能慢。

---

## 方案三：请朋友/网吧代打一次包

把整个 `e:\TraeCode\game` 文件夹拷贝给网络好的电脑，运行：

```powershell
.\scripts\build-apk.ps1
```

成功后 APK 在：

`build\app\outputs\flutter-apk\app-release.apk`

发回你即可，**只需打一次**。

## 已为你安装好的环境

| 组件 | 路径 |
|------|------|
| Flutter SDK | `E:\flutter` |
| Android SDK | `E:\Android\Sdk` |
| Android Studio | `C:\Program Files\Android\Android Studio` |

Flutter 已加入用户 PATH，新开终端可直接用 `flutter` 命令。

## iOS 说明

iOS 必须在 **Mac + Xcode** 上打包，Windows 无法直接生成 iPhone 安装包。若需要 iOS，可以：
- 借 Mac 运行 `flutter build ios`
- 或使用 GitHub Actions + Mac runner（需 Apple 开发者账号，较复杂）

## 常见问题

**Q：本地 build 一直卡住？**  
A：不要用本地打包，用 **方案一云打包**。

**Q：GitHub 访问慢？**  
A：可用 GitHub 镜像站克隆，或把代码推到 **Gitee**，在 Gitee 流水线里配置同样命令（`flutter build apk --release`）。

**Q：安装后相机权限？**  
A：扫码加入房间需要相机，首次会弹权限，点允许即可。
